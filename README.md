# 🛒 PUBG Mobile UC Store — Telegram Bot & Mini App

Удобный и быстрый бот для продажи PUBG Mobile UC с интегрированным внутриигровым магазином (Telegram Mini App). 

Бэкенд написан на **Python (Flask + pyTelegramBotAPI)**, база данных — **SQLite**, а фронтенд работает на чистом **HTML/CSS (Tailwind CSS)** и хостится прямо на **GitHub Pages**.

---

## 🚀 Основной функционал

* **Автоматический Webhook:** Бот сам настраивает вебхук на ваш сервер/ngrok при запуске.
* **Интеграция с Mini App:** При старте бот присылает красивое приветствие с кнопкой для открытия WebApp.
* **Покупка через баланс:** Списание средств происходит из локальной базы данных SQLite.
* **Система поддержки:** Сообщения из раздела «Написать разработчику» летят напрямую админу в чат. Админ может ответить пользователю обычным `Reply` (ответом) на сообщение бота.
* **Заявки на пополнение:** Пользователь уведомляет об оплате, а админ получает отмашку в чат для проверки чека.
* **Мультиязычность:** Мгновенное переключение интерфейса магазина (РУС / UZB) без перезагрузки страницы.

---

## 🛠 Технологический стек

* **Backend:** Python 3.x, Flask, pyTelegramBotAPI (telebot), Flask-CORS
* **Database:** SQLite3
* **Frontend:** HTML5, JavaScript, Tailwind CSS (через CDN)
* **Хостинг/Проброс портов:** ngrok (для локальных тестов) + GitHub Pages (для фронтенда)
